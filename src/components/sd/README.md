# Folder Khusus Unit SDIT Al-Afiyah (`sdit.alafiyah.id`)

Seluruh revisi tampilan untuk **SDIT Al-Afiyah** dikumpulkan secara terpisah di dua lokasi berikut agar tidak bercampur dengan SMP IT maupun TKIT:

1. **Komponen Tampilan Beranda & Profil SDIT (`src/components/sd/`)**:
   - `SdLandingView.tsx` — Tampilan utama Beranda SDIT (`/sd`)
   - `SdPrincipalGreetingSection.tsx` — Bagian Sambutan Kepala Sekolah SDIT (`Ust. Febrian Fauzi, S.Pd., M.Pd.`)
   - `SdWelcomeVideoModal.tsx` — Popup Video Sambutan SDIT

2. **Halaman-Halaman Rute SDIT (`src/app/sd/`)**:
   - `src/app/sd/page.tsx` — Data & Konfigurasi Beranda SDIT
   - `src/app/sd/profil/page.tsx` — Halaman Profil SDIT
   - `src/app/sd/guru/` — Halaman Struktur Organisasi & Guru SDIT
   - `src/app/sd/program/page.tsx` — Halaman Program Unggulan SDIT
   - `src/app/sd/fasilitas/page.tsx` — Halaman Fasilitas SDIT
   - `src/app/sd/dokumentasi/` — Halaman Galeri Dokumentasi SDIT
   - `src/app/sd/berita/page.tsx` — Halaman Berita & Artikel SDIT
   - `src/app/sd/spmb/` — Halaman Info, Cek Status, & Formulir Pendaftaran SPMB SDIT
